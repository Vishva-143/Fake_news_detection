# IEEE Report

## Title
AI-Powered Fake News Detection Using Text Classification

## Abstract
This report presents a beginner-friendly machine learning project for detecting fake news using text classification. The project demonstrates preprocessing, feature extraction, model training, evaluation, and deployment through a Flask application.

## Methodology
1. Data preprocessing and cleaning
2. TF-IDF vectorization
3. Model training and comparison
4. Evaluation with metrics and visualization
5. Web deployment

## Conclusion
The project shows how classical machine learning techniques can be applied effectively for fake news detection tasks.
